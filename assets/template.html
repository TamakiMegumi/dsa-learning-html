核心思想 Intuition

用「人话」解释算法为什么能工作：每一步在做什么、利用了什么性质。 例如冒泡排序的核心直觉是——每一轮都把当前未排序区间里最大的元素像气泡一样「浮」到末尾， 因为相邻比较 + 交换保证较大者总向后移动。

  • 不变式：第 $i$ 轮结束后，末尾 $i$ 个元素一定是全局最大的 $i$ 个且已就位。
  • 为何终止：最多 $n-1$ 轮后，前 $n-1$ 个就位，最后一个自然就位。

数学原理 Math

把复杂度讲清楚，必要时推导。例如冒泡排序：外层 $n-1$ 轮，第 $i$ 轮内层比较 $n-1-i$ 次， 比较总次数为等差数列：

$$ \sum_{i=0}^{n-2}(n-1-i) = \frac{n(n-1)}{2} \in \Theta(n^2) $$

交换次数不超过比较次数（仅当逆序才交换），故最坏与平均都是 $\Theta(n^2)$， 最好情况（已有序）仍为 $\Theta(n)$ 轮比较、0 次交换。

算法：自由函数 Algorithm

下面给出 bubbleSort 自由函数。数组只是承载元素的容器（非本讲主角）， 因此直接用 STL 的 std::vector<T>，无需自己写数据结构；算法写成函数便于单独测试。

bubble_sort.cpp
#include <vector>
#include <utility>

// 冒泡排序：相邻两两比较，大的往后冒
template <typename T>
void bubbleSort(std::vector<T>& a) {
    int n = static_cast<int>(a.size());  // 数组长度
    for (int i = 0; i < n - 1; ++i) {          // 外层：共 n-1 轮
        for (int j = 0; j < n - 1 - i; ++j) {  // 内层：未排尾区
            if (a[j] > a[j + 1]) {             // 前面大于后面
                std::swap(a[j], a[j + 1]);      // 交换二者
            }
        }
    }
}
写法保守、兼容 C++20：仅用 template、std::vector、std::swap 与清晰注释；未使用 concept / ranges / <=> 等易混淆新特性。
